# 产品设计文档

> 可交互的布局演示：直接用浏览器打开 [demo/index.html](demo/index.html)，无需安装任何依赖，界面里的翻页、搜索、统计、老板模式都能点。

## 1. 一句话定位

本地优先、零后端的桌面阅读器：不用登录、不联网，一个文件夹拷走就能用。

## 2. 目标用户与场景

| 场景 | 需求 |
| --- | --- |
| 长时间读书 | 分页阅读、排版舒服、长时间不累眼 |
| 找内容 | 想起来某句话，能立刻搜到并跳过去 |
| 上班摸鱼 | 一键把窗口缩到角落、半透明，远看不像在读书 |
| 碎片时间 | 随时关掉，下次打开还在原处 |

## 3. 范围

### 这一版做

- **支持 TXT / EPUB**（v11.2 起增加 **PDF**：原文件保存，一页一屏按页渲染）
- 分页阅读（替代当前滚动阅读）
- 书内搜索
- 阅读统计
- 老板模式（可拖动的小窗）
- 书签（定位模型顺带产出，成本极低）
- 排版设置（现有字号/行距/主题/版心，适配分页）

### 这一版不做

- MOBI / AZW3（格式扩展留到后续版本）
- 账号、云同步、跨设备
- 划线批注、笔记导出
- 社交、书评、推荐

## 4. 核心流程

```
导入 EPUB → 书架 → 打开并分页阅读 → 记进度/加书签
                      ├→ 搜索并跳转
                      ├→ 老板模式（随时一键隐身）
                      └→ 返回书架（看到阅读统计）
```

## 5. 功能设计

### 5.1 书架

- 书籍卡片：封面（EPUB 提取，缺省用书名首字）、书名、作者、进度、字数/章节数
- 操作：继续阅读、删除（删除只删本地副本）
- 导入：文件对话框（可多选）+ 拖拽
- 排序：最近阅读优先；空书架给出明确的导入引导

### 5.2 阅读器（分页）

- **一页一屏**，整页翻动，不留滚动条
- 翻页方式：`←/→`、`PageUp/PageDown`、点击左右区域、触控板横滑
- 顶部信息条：书名 + 章节名 + 页码（当前页/总页数）
- 底部进度：章节进度 + 全书百分比
- 目录：侧栏章节列表，点击跳转，当前章高亮
- 关键要求：**改字号 / 改窗口大小后，位置不丢**（按锚点重新分页后回到原句）

### 5.3 书内搜索

- 快捷键 `Ctrl+F` 呼出，输入即时出结果
- 结果列表：命中片段（前后文高亮）+ 章节名 + 位置
- 点击结果：跳到该页，并短暂高亮命中词
- 支持「下一个/上一个」循环跳转
- EPUB 按章节文本建索引；TXT 直接扫描

### 5.4 阅读统计

- 记录每次阅读的时长与进度变化
- 展示：
  - 今日阅读时长
  - 累计时长 / 累计天数
  - 最近 7 天柱状图
  - 平均阅读速度（字/分钟）
- 入口：书架顶部「统计」按钮
- 数据只存本地，可一键清空

### 5.5 老板模式

一键隐身，再按一次精确还原。

| 项 | 设计 |
| --- | --- |
| 触发 | 全局热键（默认 `Ctrl+Alt+B`，可改），窗口失焦也能用 |
| 尺寸 | 默认约 420×300，按上次使用尺寸 |
| 位置 | **默认左下角，可拖动**；记住最后位置，还原时回到进入前的位置和大小 |
| 外观 | 半透明两档（轻度 72% / 隐蔽 38%）；隐藏侧栏、标题、进度条，只留正文 |
| 拖动 | 顶部一条极薄的可拖动手柄（悬停才显示） |
| 置顶 | 开启，且不进任务栏 |
| 降级 | 个别显卡/远程桌面忽略透明度时，退化为「小窗但不透明」，仍可正常阅读 |

### 5.6 排版设置

- 字号、行距、版心宽度、三套主题、宋体/黑体
- 分页模式下改动即时重排并保持位置
- 设置全局生效，按书可覆盖（后续版本）

### 5.7 书签

- 一键加书签，记录锚点 + 章节 + 一段摘要
- 书签列表在侧栏，点击跳转
- 定位用锚点而非页码，改字号不漂移

## 6. 数据与定位模型

- **锚点定位**：全书统一用「章节 ID + 章内字符偏移」记录位置，页码/百分比/书签/搜索命中全部由它派生
- 书籍文件与索引存 `data/library/`，原文件删除不影响阅读
- 所有数据本地 JSON，无数据库、无后端

## 7. 技术约束

| 约束 | 说明 |
| --- | --- |
| 桌面壳 | Electron + React + TypeScript，前端打包进 asar |
| 分页实现 | 用 CSS 多列排版配合翻页偏移，避免自研断行算法 |
| EPUB 渲染 | 解析 ZIP + OPF + XHTML，注入主题样式，禁用脚本 |
| Windows 11 25H2 | 必须带 `--no-sandbox` 启动，已由 `TXT阅读器.exe` 启动器带上 |
| 离线 | 不请求任何网络资源，EPUB 内置资源全部本地化 |

## 8. 验收标准

- 打开常见 EPUB 排版正确，目录、封面、章节顺序无误
- 改字号/缩放窗口后仍在原句，误差不超过一段
- 搜索能在 1 秒内出结果并精准跳转
- 老板模式热键响应 < 0.3 秒，还原后窗口位置与大小完全一致
- 统计数字与实际阅读时长误差 < 5%
- 关掉应用重开，进度、书签、设置全部保留
